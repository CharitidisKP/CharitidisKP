## Hello, I'm Konstantinos Charitidis! 
Bioinformatician in Stockholm. I work on spatial and single-cell transcriptomics, bulk RNA-seq and proteomics in autoimmune disease. 
I work mostly in R and Bash, build pipelines in Nextflow, keep my code in Git and run it in Conda environments and Apptainer containers so the analyses are reproducible.

- [CosMx-Nf](https://github.com/CharitidisKP/CosMx-Nf): Nextflow (DSL2) pipeline for CosMx spatial transcriptomics, from QC and cell typing to spatial analysis, cell-cell communication and differential expression.
- Publication: Glycomic profiles before and after treatment for lupus nephritis, Cells 2026 [Cells 2026](https://doi.org/10.3390/cells15050433).
